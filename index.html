Tim's Personal Assistant

A private automation assistant for its owner's personal use. This application connects locally operated Google Workspace CLI or MCP tools to an AI assistant to help with authorized tasks involving Google Drive, Docs, Sheets, Gmail, and Calendar.

How it works

The owner signs in through Google's OAuth consent flow and grants the permissions required for the selected services. The tools use those permissions to read information or perform actions requested by the owner. The application is not affiliated with or endorsed by Google.

This application has no public registration and is not offered as a service to other users. This website contains information only; it does not host the MCP server, collect OAuth credentials, or provide a sign-in form.
