Privacy Policy

Effective September 29, 2026.

Tim's Personal Assistant is an application for its owner's personal use. It is not available for public registration.

Google data access and use

The application accesses Google data within the permissions granted by the owner through OAuth. Depending on the enabled services and requested task, this can include files, documents, spreadsheet and presentation data, email messages and settings, calendar events, forms and responses, tasks, contacts, Chat spaces and messages, Apps Script projects and deployments, and search results. This data is used to answer the owner's questions and carry out requested actions, including editing or deleting content, sending messages, managing tasks and contacts, and deploying or executing scripts when explicitly requested by the owner.

Storage and sharing

In the local configuration described here, OAuth credentials and tokens are stored on the owner's device by the selected CLI or MCP software. Task data may also be retained in local files, assistant conversations, or logs according to the configured software.

Relevant task data may be sent to the AI model providers configured by the owner in the assistant. Those providers process and retain data according to their own policies and the owner's account settings. The application uses Google's APIs to perform authorized actions.

The application does not sell Google user data, use it for advertising, or intentionally share it with parties unrelated to the owner's tasks. Google data is not used by this application to train a generalized AI model.

Controls and deletion

The owner can revoke access through Google Account third-party connection settings and delete locally stored tokens, downloaded files, logs, and conversation data. Data already sent to an AI provider must be managed using that provider's deletion and retention controls.

Limited use

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This website

This static website is hosted by GitHub Pages. It has no application analytics, advertising, OAuth token collection, or sign-in form. GitHub may process standard hosting request information under its own privacy policy.
